## 全书总钉（五夜必须形成的链条）

1. **目的论**取代原因论（过去不决定现在的意义）  
2. **一切烦恼来自人际关系**  
3. **课题分离** → 才能谈自由  
4. **自由 = 被讨厌的勇气**（金句必须是逼出来的，不是插播）  
5. **共同体感觉** = 自我接纳 · 他者信赖 · 他者贡献（三角齐全）  
6. **横向关系**贯通二～四夜  
7. **此时此刻**收束线状人生幻想  
8. **幸福的勇气** + 踏出一步（终章）
