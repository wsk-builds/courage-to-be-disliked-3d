## 1. 固定角色（第一卷不增主卡）

| 角色 ID | 显示名 | 身份 | 视觉关键词 | 表演基调 |
|---------|--------|------|------------|----------|
| `philosopher` | 哲学家 | 年长、阿德勒派实践者 | 银灰半秃、胡须、眼镜、青灰长袍、从容坐姿 | 低声量、留白、开放手势 |
| `youth` | 青年 | 不满现状的挑战者 | 深色乱发、深外套、略驼/前倾 | 急、辩、握拳→后期松弛 |
| `narrator` | 旁白 | 非实体 | 无模型（镜头/环境叙事） | 沉稳纪录片 |

**禁止**：中途改脸型比例、换服装主色、换眼镜有无（除非剧情明确）。  
**允许**：同一模型上的 `emotion` / `gesture` / 坐立 / 走位。

### 1.1 人物尺度（代码锁）

| 参数 | 值 | 说明 |
|------|-----|------|
| 哲人 `height` | `1.02` | `createPhilosopher()` |
| 青年 `height` | `0.98` | `createYouth()` |
| 入座 root.y | `0.15` | 与椅面匹配 |
| 站立骨盆参考 | ~`0.95` | 角色内部 |

### 1.2 服装主色（勿漂移）

| 角色 | 肤色 | 发 | 衣/袍 | 裤 |
|------|------|----|-------|-----|
| 哲人 | `0xc9a882` | 银灰 `0xb8b0a0` | 袍 `0x3a4558` / 衫 `0x2c3344` | `0x252530` |
| 青年 | `0xd4b08c` | 深 `0x1a1510` | 外套 `0x3a3848` / 衫 `0x5a4038` | `0x2a2830` |

### 1.3 情绪与手势词表（全 Part 共用枚举）

**emotion:** `calm` | `tense` | `angry` | `thoughtful` | `hopeful`  

**gesture:** `idle` | `open` | `welcome` | `point` | `think` | `gesture` | `clench` | `lean`  

新动作先扩 `characters.js`，再在台词里引用。

### 1.4 弧光（跨夜一致）

| 阶段 | 青年 | 哲学家 |
|------|------|--------|
| P00–P02 | 攻击性强、坐姿紧 | 始终稳，偶 think |
| P03–P04 | 自卑暴露，有动摇 | 引导、少刺激 |
| P05–P06 | 辩不过，开始听 | 课题分离说清 |
| P07–P08 | 认真求问 | 谈共同体 |
| P09–P10 | 起身、hopeful | 目送，不挽留 |

## 2. 场景圣经

### 2.1 主场景集合

| 场景 ID | 描述 | 使用 Part |
|---------|------|-----------|
| `exterior` | 古城郊外、路径、树、远城灯火 | 序、进出 |
| `door` / 门廊 | 门半开、台阶 | 来访、离去 |
| `study` | 书房对谈主舞台 | 几乎全部夜谈 |
| `closeup` | 对谈特写机位 | 金句、激烈辩 |
| `snow` | 门外新雪、月光 | P10 终章 |

**不新建第二套房子。** 一夜一屋，靠 `nightPhase` 变氛围。

### 2.2 锁定锚点（`world.anchors`）

| 锚点 | 坐标（约） | 用途 |
|------|------------|------|
| `philosopherSeat` | `(-1.15, 0, -1.6)` | 哲人椅 |
| `youthSeat` | `(1.15, 0, -0.9)` | 青年椅 |
| `houseDoor` | `(0, 1.2, 6.2)` | 门区 |
| `studyCenter` | `(0, 1.4, -1.2)` | 对谈中心 |

改家具布局必须同步改锚点与 `main.js` 入座逻辑。

### 2.3 夜次氛围（`nightPhase`）

| phase | 灯光 | 窗外 | 桌上 | 雪 |
|-------|------|------|------|-----|
| `prologue` | 暖灯中等 | 远城清晰 | 茶具整齐 | 无 |
| `night1` | 暖、稳 | 同 prologue | 同左 | 无 |
| `night2` | 略暗 | 雾略重 | 可多一本书摊开 | 无 |
| `night3` | 烛火感更强 | 更深 | 茶续过 | 无 |
| `night4` | 偏暖金 | 静 | 可有信笺/笔记 | 无 |
| `night5` | 冷暖交界 | 将雪/起雪 | 收束感 | 无→将雪 |
| `ending` | 冷月光+门内余暖 | **雪** | 青年离席 | 有 |

实现方式：在 `world.js` 增加 `setNightPhase(phase)`（后续 Part 开发时落地），**禁止**复制整屋。

### 2.4 美术关键词

- 时代感：暧昧的「千年古都郊外」——日式/欧式书房混搭克制，不卡通、不赛博  
- 材质：木、纸、布、旧铜；避免塑料高光  
- 色板：夜外冷蓝灰 `#0a0e16`；室内暖 `#ffcc88` 灯；雪 `#e8eef5`

## 4. 质量标准（每 Part 验收）

- [ ] 人物脸/衣与 P00 同一套模型  
- [ ] 入座位置无悬空、无穿模  
- [ ] 镜头切换 1–2 秒内可读  
- [ ] 情绪与台词不矛盾（愤怒时不 hopeful 脸）  
- [ ] 旁观可 WASD 自由走，不碎碰撞到关键演出  
- [ ] 无新增「第二版青年」临时网格

## 5. 变更流程

1. 改圣经（本文）  
2. 改 `characters.js` / `world.js`  
3. 跑 P00 回归（序章是否仍正常）  
4. 再推进当前 Part  

大改模型时：**冻结剧情写入**，先过视觉回归。
