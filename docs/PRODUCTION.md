# 《被讨厌的勇气》· 全本旁观世界制作总纲

> 目标：把整本书做成**可旁观、可交互**的 3D 世界。  
> 配音：现阶段继续用**浏览器系统语音**；你选定豆包/阿里音色后，再统一换成**预渲染音频**。  
> 文本：采用「忠于剧情与概念的改编对白」，**非出版社原文逐字照搬**（避免版权风险，同时适合表演与镜头）。

---

## 1. 原则

| 原则 | 说明 |
|------|------|
| **单源建模** | 人物只维护 `characters.js`，场景只维护 `world.js`；各章只换剧情/镜头/灯光状态，不复制模型 |
| **锚点锁定** | 座椅、门、书桌、室外路径等坐标写入「场景圣经」，全章共用 |
| **分块交付** | 按「制作单元」验收，每单元可独立旁观完整叙事弧 |
| **先骨架后肉** | 先跑通对白时间线 + 镜头 + 走位，再加道具互动与支线 |
| **声画可替换** | 台词带稳定 `lineId`，系统 TTS / 预渲染 mp3 可热切换 |

## 2. 原书叙事结构（五夜 + 序）

原书以**青年 × 哲学家**的连续夜谈展开（阿德勒心理学入门对话录）：

| 书中结构 | 核心命题（制作时抓住的「戏核」） |
|----------|----------------------------------|
| **引言** | 郊外拜访；「世界无比单纯」vs 青年的不服 |
| **第一夜** | 不幸是谁的错？目的论、否定创伤决定论、不幸与「不改变」 |
| **第二夜** | 一切烦恼来自人际关系；自卑感/自卑情结；权力斗争；人生课题 |
| **第三夜** | 课题分离；否定认可欲求；自由 = 被讨厌的勇气 |
| **第四夜** | 共同体感觉；横向关系；他者贡献；认可的真正来源 |
| **第五夜** | 活在当下；人生是连续的点；幸福的勇气；雪夜踏出一步 |

全书主场景几乎始终是：**哲学家的书房 + 屋外夜色/雪**。这是优势——场景可高度复用，靠**灯光、道具状态、天气、青年姿态**区分「第几夜」。

## 3. 制作单元划分（建议按此排期）

每个 **Part** = 一次可交付的制作切片（约 8–20 分钟旁观量，可再调）。

| Part ID | 名称 | 对应原书 | 状态 | 场景重点 | 表演重点 |
|---------|------|----------|------|----------|----------|
| **P00** | 序章 · 夜访 | 引言 | ✅ ready | 郊外→门廊→入座 | 青年怒气进门；哲人从容迎客 |
| **P01** | 第一夜 · 上：原因与目的 | 第一夜前半 | ✅ ready | 书房 night1 氛围+展开书 | 否定「创伤决定论」；青年激烈反驳 |
| **P02** | 第一夜 · 下：不幸的选择 | 第一夜后半 | ✅ ready | night1 书房 | 「不改变」；从现在开始；第一夜收束 |
| **P03** | 第二夜 · 上：人际与自卑 | 第二夜前半 | ✅ ready | night2 氛围+人际道具 | 再访；人际烦恼；自卑感/情结 |
| **P04** | 第二夜 · 下：竞争与课题 | 第二夜后半 | ✅ ready | night2 | 横向关系；权力斗争；三大课题 |
| **P05** | 第三夜 · 上：课题分离 | 第三夜前半 | ✅ ready | night3 课题双盘 | 分清「谁的课题」 |
| **P06** | 第三夜 · 下：被讨厌的自由 | 第三夜后半 | ✅ ready | night3；金句 closeup | 认可欲求；自由即被讨厌的勇气 |
| **P07** | 第四夜 · 上：共同体感觉 | 第四夜前半 | ✅ ready | night4 暖光+杯阵 | 共同体感觉；横向 vs 纵向 |
| **P08** | 第四夜 · 下：他者贡献 | 第四夜后半 | ✅ ready | night4 | 贡献感；我在这里就好 |
| **P09** | 第五夜 · 上：此时此刻 | 第五夜前半 | ✅ ready | night5 沙漏 | 人生是点的连续；当下 |

> **P00** 现有内容是「全五夜的浓缩预告片」。正式制作时：保留 P00 作序章，把现有「第一夜/勇气/雪」拆句**归入** P01–P10，避免与后文重复堆叠。

### 可选扩展（第二期，不阻塞主线）

- **支线镜头**：青年回忆「出不了门的朋友」（书中案例）→ 短暂闪回小场景  
- **道具互动**：观众可点书架、烛火、窗、茶，触发旁白短注（非必须）  
- **续作《幸福的勇气》**：新人物（青年友人等）——届时再扩角色圣经

## 4. 推荐制作顺序

```
① 锁定一致性圣经（人物/场景/镜头）     ← 本次已建立 docs/
② 打磨 P00 为「标准样板间」           ← 质量锚点
③ P01 → P02（第一夜完整）
④ P03 → P04（第二夜）
⑤ P05 → P06（第三夜，含书名金句）
⑥ P07 → P08（第四夜）
⑦ P09 → P10（第五夜 + 雪夜终章）
⑧ 全局串联、章节地图、预渲染配音替换
```

每完成一个 Part：

1. 对白时间线可完整播放  
2. 镜头 cue 不穿帮  
3. 人物情绪/手势与台词匹配  
4. 不破坏 P00 已锁定的模型与锚点  
5. README / manifest 状态更新

## 5. 工程目录约定（分 Part 不拆模型）

```
content/
  manifest.js          # 全书 Part 列表与加载顺序
  parts/
    part-00-prologue.js
    part-01-night1-a.js
    ...
docs/
  PRODUCTION.md        # 本文件
  CONSISTENCY.md       # 人物/场景/镜头一致性
  VOICE_CASTING.md     # 你选定音色后填写
characters.js          # 唯一人物源
world.js               # 唯一场景源
voice.js               # 系统 TTS；日后 + 预渲染播放器
story.js               # 兼容层：聚合当前启用的 Part
main.js                # 播放器 / 旁观操控
```

**禁止**：为某一夜复制一份 `characters_night2.js` 导致脸不一致。  
**允许**：`world.setNightPhase('night3')` 这类**状态切换**（灯光、雪量、窗外、桌上道具）。

## 6. 每 Part 的内容规格（模板）

每个 `part-XX-*.js` 导出：

```js
export const PART = {
  id: 'P01',
  title: '第一夜 · 上：原因与目的',
  bookRef: '第一夜',
  estimatedMinutes: 12,
  nightPhase: 'night1',      // 驱动场景状态
  lines: [ /* Line[] */ ],
};
```

每条 `Line` 建议字段：

| 字段 | 用途 |
|------|------|
| `id` | 稳定 ID，如 `P01-L012`（预渲染文件名） |
| `speaker` | `narrator` \| `philosopher` \| `youth` |
| `text` | 显示 + TTS/预渲染文案 |
| `duration` | 保底秒数（有预渲染时以音频为准） |
| `camera` | 镜头 cue |
| `emotion` / `gesture` | 角色表演 |
| `stage` | 可选：走位/道具触发 |

## 7. 配音策略（与你的计划对齐）

| 阶段 | 策略 |
|------|------|
| **现在** | `voice.js` 浏览器系统语音；不阻塞建模与剧情 |
| **你选角中** | 豆包 / 阿里试听；结果写入 `docs/VOICE_CASTING.md` |
| **选定后** | 预渲染：`audio/{lineId}.mp3` + 播放器替换 Web Speech |
| **原则** | 先全本或先单 Part 批量生成皆可；**lineId 稳定**最重要 |
